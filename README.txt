EDA'S CAFE — STATIC WEBSITE

Upload the CONTENTS of this folder (index.html, styles.css, cakes/,
qr-code.png and the other files) to your web host's public website folder.
No Node.js, build step, database, or JavaScript is required.

This standalone page reproduces the currently visible public homepage.
Its visible links work: WhatsApp, email, Just Eat, Instagram, Google Maps,
the QR code, and the Eda's Cafe home link. The "Find Us" pin is built into
index.html as an inline SVG and links directly to Google Maps. No Google
Maps API key or authentication is required. The QR code links to
https://www.eda-cafe.co.uk, so point that domain at your new host.

The original application's shop, orders, newsletter, custom-cake form,
admin and uploaded-file features need an API/database and are NOT part
of this static page. The Google Maps button opens Google Maps in a new
tab and needs an internet connection.
